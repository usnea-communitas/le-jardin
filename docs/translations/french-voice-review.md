# Écoute de la voix française du jardin

*For maintainers: this is the checklist for a native French listener (part 7 of the plan, H8). The 49 recordings and how they were made are described in [`docs/ASSET_PROVENANCE.md`](../ASSET_PROVENANCE.md); the list of lines is `assets/i18n/audio.fr.json`. To redo a line: generate it again in the same ElevenLabs flow (voice Corinne, `eleven_v3`, language `fr`), put the take in a folder as `story/<file>` or `garden-voice/<file>`, change its text in `audio.fr.json` if needed, then run `node scripts/normalize-voice.mjs fr <folder>` (it levels every take in the folder, so copy the other kept takes there too, or level only the new one by hand with the same settings), `node scripts/sync-audio-captions.mjs fr`, `npm run generate` and `npm test`.*

Merci d’écouter Le Jardin en français. Le jardin de Menet parle au joueur, qu’il tutoie : sept scènes au début de l’histoire, puis 42 phrases pendant le jeu. Il nous manque l’oreille d’une personne dont le français est la langue maternelle.

## Comment écouter

- Dans le jeu : <https://permaculture-garden.vercel.app/?lang=fr>, puis « Commencer l’histoire ». Le reste des phrases arrive en jouant (on peut aussi les écouter une par une ci-dessous).
- Chaque phrase seule : les liens « écouter » dans le tableau. Le texte du tableau est exactement ce que la voix doit dire ; c’est aussi le sous-titre affiché à l’écran.

## À quoi faire attention

1. **Prononciation.** Le nom du village (Menet, « Me-nè »), les mots rares (*brassicacées*, *turricules*, *carabes*, *paillis*), les liaisons et les nombres de syllabes.
2. **Le ton.** Une voix calme et chaleureuse de jardin, qui parle à des jeunes : ni publicitaire, ni trop intime ou séductrice, ni enfantine.
3. **Le rythme.** Trop lent, trop rapide, une pause au mauvais endroit, une fin coupée ou un souffle gênant.
4. **L’émotion.** Elle correspond au moment : inquiétude quand des pucerons ou des limaces arrivent, émerveillement, gratitude à la fin.
5. **Le texte.** Une tournure qu’un francophone ne dirait pas, une phrase ambiguë, une erreur de sens. Le jardin parle de lui au masculin (« je suis devenu ») ; à l’oral cela ne s’entend presque jamais, mais dites-nous si quelque chose sonne faux avec une voix de femme.
6. **Ce qui manque.** Une phrase qui ne joue pas, ou qui est en anglais alors que le jeu est en français.

## Comment nous le dire

Notez l’identifiant de la phrase (par exemple `aphid-2`), ce que vous entendez et, si possible, ce qu’il faudrait dire. Écrivez dans [l’issue #5](https://github.com/usnea-communitas/le-jardin/issues/5) sur GitHub, ou par e-mail à l’adresse indiquée dans [SECURITY.md](../../SECURITY.md). Nous refaisons uniquement les phrases concernées, avec la même voix.
