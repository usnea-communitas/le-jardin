# Playtest kit

Everything needed to run Le Jardin with a group of players and to bring what you saw back to the project: a session plan, an observation sheet, a short questionnaire for players, a consent text and the steps for filing a report. The kit is in English and Czech; print what you need.

| | English | Česky |
|---|---|---|
| Session plan (60–90 minutes) | [session-protocol.md](en/session-protocol.md) | [protokol-sezeni.md](cs/protokol-sezeni.md) |
| Observation sheet, one per observed player or pair | [observation-sheet.md](en/observation-sheet.md) | [pozorovaci-arch.md](cs/pozorovaci-arch.md) |
| Questionnaire for players (anonymous, paper) | [player-questionnaire.md](en/player-questionnaire.md) | [dotaznik-pro-hrace.md](cs/dotaznik-pro-hrace.md) |
| Consent text | [consent.md](en/consent.md) | [souhlas.md](cs/souhlas.md) |
| Filing the report | [reporting.md](en/reporting.md) | [jak-zapsat-ohlasy.md](cs/jak-zapsat-ohlasy.md) |

Reports go into an issue made from the *Playtest report* template, linked from [issue #8](https://github.com/usnea-communitas/le-jardin/issues/8). Issues are public: never put names, photos or anything else that identifies a player into them.

Nothing in the kit needs an account. The game saves progress only in the browser of the device it runs on; when the device is online and a player opens the Living Lesson, the game sends the AI model an anonymous summary of the garden (element types, season, relationship counts and the language) — never a name, a written reflection or the saved game. Le Jardin is an independent project and is not affiliated with or endorsed by Erasmus+.
